# C-01 LangGraph（LangChain）

- **一句话结论**：LangGraph 把 agent 循环**显式建模为状态图**（节点=处理步骤、边=转移、状态=共享数据），并以内置 **checkpointer** 实现节点级持久化与 HITL 暂停/恢复——它是"stateful production workflows"的默认选择（Klarna/Replit/Uber/LinkedIn 生产使用）。

## 六元组速览

| 维度 | LangGraph 答案 |
|---|---|
| L 循环 | **显式 StateGraph**：节点/边/条件边；循环=图中环；支持并行分支、子图、递归 |
| S 状态 | 一等公民：共享 State schema；**checkpointer 每节点持久化**（内存/Redis/SQLite/Postgres），崩溃后从 checkpoint 续跑 |
| I_act | 节点内调用模型/tool（LangChain 工具体系）；2026 新增 pre/post model hooks |
| C 上下文 | 状态即上下文（消息在 state 里）；summarization 节点做压缩 |
| V 验证 | 停止条件=图拓扑（到达 END）；LangSmith 深度可观测 |
| 多智能体 | 子图、supervisor 模式、handoff 边 |

## 核心机制（3 条）

1. **图即程序**：`StateGraph` 定义节点与边，`compile()` 成可执行图；状态 schema 声明式定义，任何节点读写共享状态——**确定性控制流**（vs AgentScope 的自由循环）。
2. **checkpointing 是灵魂**：每次节点执行后存 checkpoint → `interrupt()` 在任意节点暂停等人/等事件 → 恢复时从断点继续；这是 durable execution + HITL 的基础。
3. **2026 演进**（1.x）：node caching、deferred nodes、pre/post model hooks、content-block streaming——生产化补齐。

## 与 AgentScope 对照

- 循环：AgentScope 用 `_next_action` 状态机（隐式、运行时决定）；LangGraph 用显式图（设计期决定）——**前者灵活、后者可控可审计**
- 状态：AgentScope 的 S=AgentState+Storage（会话层）；LangGraph 的 S=节点级 checkpoint（可续跑粒度更细）
- 适用：LangGraph 适合"流程必须确定、可审计"的场景；AgentScope 适合"让模型自主发挥"的场景
