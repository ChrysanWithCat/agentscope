# C-15 OpenClaw

- **一句话结论**：OpenClaw（TypeScript，~100K+ stars）定位"**自主个人助理**"型 harness——把记忆、工具广度（浏览器/邮件/文件/通信）、权限与持续运行做成面向"一个人长期使用"的设计。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | 持续运行的 agent 循环（长时任务、后台执行） |
| I_act | 工具广度优先：浏览器、文件、通信（IM/邮件）、代码执行等大量环境工具 |
| C 上下文 | 长期记忆（个人上下文：偏好/历史/关系） |
| S 状态 | 长期状态（跨会话持续） |
| V 验证 | 权限控制（个人场景的敏感操作确认） |
| 多智能体 | 多 agent/工具编排 |

## 核心机制（3 条）

1. **个人助理范式**：与"生产多租户服务"不同，OpenClaw 为"一个用户长期使用"设计——**记忆与偏好的跨会话保持**是核心（agent 要"认识你"）。
2. **工具广度即能力**：接入越多真实世界工具（浏览器/IM/邮件），个人助理越有用——I_act 的广度优先于深度。
3. **2026 harness 热潮代表**：~100K stars 说明"个人自主 agent"是 2026 主流需求（与 Hermes 同类，一个偏学习、一个偏助理）。

## 与 AgentScope 对照

- 场景：OpenClaw 个人助理（单用户长时）vs AgentScope 多租户服务（多用户并发）
- 记忆：OpenClaw 个人上下文优先 vs AgentScope 三后端记忆中间件（可配）
- 工具：OpenClaw 环境工具广度 vs AgentScope 沙箱+内置编码工具（深度）
- 迁移点：都是"harness = 循环+工具+记忆+权限"，场景决定侧重
