# C-12 Mastra（TypeScript）

- **一句话结论**：Mastra 是 **TypeScript-first** 的 agent 框架（~22-24K stars、~300K 周 npm 下载），核心抽象为 **Agents / Workflows / LLM 网关**，**MCP 原生**支持——代表"TS 生态 harness"的成熟形态（2026 TS 生态 leader）。

## 核心机制（3 条）

1. **TS-first 完整栈**：与 Python 框架对等的能力（agents/workflows/RAG/MCP）在 JS/TS 生态里做齐——TS 团队无需跨语言。
2. **MCP 原生**：MCP 是 Mastra 工具接入的默认协议——"工具生态即 MCP 生态"，与 Claude/AgentScope 的 MCP 路线一致（跨语言共识）。
3. **LLM 网关**：统一模型接入（多家供应商）+ 可观测——TS 生态的"模型无关"做法。

## 与 AgentScope 对照

- 语言：Mastra TS / AgentScope Python——设计哲学可迁移（组件/循环/协议），API 不同
- 工具协议：都走 MCP（共同语言）
- 编排：Mastra Workflows 显式步骤 vs AgentScope 自由循环
- 定位：Mastra TS 生态 web 应用嵌入；AgentScope 自托管 Python 服务
