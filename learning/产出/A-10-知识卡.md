# A-10 扩展模块速览（一句话速查表）

- **一句话结论**：AgentScope 的扩展模块全部围绕主循环的三个接入点生长——**进上下文（RAG/记忆/上下文）**、**出动作（沙箱/MCP/Skill/工具）**、**换交互形态（语音/实时/分类/终端）**；每个模块的入口类都能从 `__init__.py` 找到。

## 速查表（模块 → 入口类 → 一句话机制）

| 模块 | 入口类（`__init__.py`） | 核心机制 |
|---|---|---|
| **RAG 知识库** | `KnowledgeBase` | 解析器（Text/PDF/PPT/Word/Excel/Image）→ 分块（ApproxTokenChunker）→ 向量库（Qdrant/Milvus/MongoDB/ES）→ 检索注入；`RAGMiddleware` 挂到上下文 |
| **Embedding** | `EmbeddingModelBase` | DashScope/OpenAI/Gemini/Ollama 四家 + `FileEmbeddingCache` 缓存 |
| **长期记忆** | `AgenticMemoryMiddleware` / `Mem0Middleware` / `ReMeMiddleware` | 统一记忆协议（add/retrieve），三种后端：文件型 / Mem0 / ReMe；挂在 `on_reasoning` |
| **MCP** | `MCPClient`（`StdioMCPConfig`/`HttpMCPConfig`） | 连接外部 MCP Server → `MCPTool` 适配进 Toolkit |
| **Skill** | `Skill` / `LocalSkillLoader` | 技能包（frontmatter 元数据 + 代码）加载 → 注册为工具 |
| **SOP 引擎** | `SOPEngine` / `SOP` / `SOPStep` | 结构化步骤编排多智能体（含 `VerificationResult` 验证），区别于自由 ReAct |
| **流水线** | `GoalPipeline` | 按固化逻辑/目标跑多智能体，对外统一接口 |
| **工作空间/沙箱** | `WorkspaceBase` / `LocalWorkspace` / `DockerWorkspace` 等 | 隔离代码执行：local/Docker/E2B/Daytona/K8s/OpenSandbox/AppleContainer/Bubblewrap；`Offloader` 把压缩上下文卸载到沙箱 |
| **实时语音** | `RealtimeAgent` / `RealtimeModelBase` | 四家实时 API（DashScope/OpenAI/Gemini/xAI）+ Transport（LocalAudioTransport）+ VAD + 音频事件流 |
| **TTS** | `TTSModelBase` | DashScope（含 CosyVoice/实时）/OpenAI/Gemini |
| **分类器** | `ClassifierModelBase` / `JevClassifierModel` | Binary/Choice/Score 三类问题 → 结构化判定 |
| **A2A** | `A2AAgent` | A2A 协议与远端智能体互操作 |
| **终端交互** | `launch_console` / `ChatUI`/`MessagesUI` | Console（流式+工具确认）与 TUI（textual） |

## 扩展模块的接入点归纳（迁移点）

```
进上下文：RAGMiddleware / 记忆中间件 / InjectionConfig 注入 ──▶ on_reasoning / compress_context
出动作：MCPTool / Skill / FunctionTool / workspace 沙箱工具 ──▶ Toolkit（I_act）
换形态：RealtimeAgent / TTS / Classifier / Console / TUI ──▶ 新的交互前端（I_obs）
```

对应 harness 五维：RAG/记忆=Context Management，沙箱=Execution，MCP/Skill=Tool System，语音/终端=I_obs 变体。

## 关键源码位置

- 各模块：`rag/_knowledge.py`、`workspace/_base.py`、`mcp/_mcp_client.py`、`skill/_local_loader.py`、`sop/_engine.py`、`pipeline/_goal_pipeline.py`、`agent/_realtime/`、`tts/`、`classifier/`、`embedding/`、`agent/_a2a_agent.py`
