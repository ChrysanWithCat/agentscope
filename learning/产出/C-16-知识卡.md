# C-16 DeepSeek Harness（dsh）

- **一句话结论**：DeepSeek Harness（`dsh`，DeepSeek AI 开源，MIT）以 "**Everything is a Plugin**" 为架构纲领——**模型、工具、技能、会话、沙箱、存储、循环、调度、UI 全部由插件组成**，由 **Cordis 插件内核**管理装载/卸载/依赖，是 2026 年增长最快的开源 harness 之一（freeCodeCamp 与 Claude Code、Hermes 并列）。

## 核心机制（5 条）

1. **Agent = Model + Harness**：官方等式——模型是推理引擎，harness 是控制中心（环境交互、工具契约、上下文流转、沙箱）。
2. **一切皆插件**：能力以插件为单位（Capabilities as plugins），Cordis kernel 管理 mount/unmount 与依赖关系——**可自由替换、灵活重组**，换模型/工具/沙箱插件不需要改 harness 源码。
3. **Cordis 插件内核**：显式依赖关系连接各模块（对比 monolithic 架构——这是"可组合 harness"的极端形态）。
4. **原生 KV Cache 优化**：面向推理效率的工程优化（生产级执行脚手架）。
5. **开发者预览**：v0.1 已开源（MIT）——学习价值极高：插件化 harness 的完整样本。

## 与 AgentScope 对照（关键迁移点）

- 扩展机制：dsh 插件内核（一切皆插件、运行时装载）vs AgentScope 中间件+Toolkit（钩子+注册表）——**一个"装模块"，一个"挂钩子"**
- 组件清单：dsh 把模型/工具/会话/沙箱/存储/循环/调度/UI 全插件化；AgentScope 组件化但由 `create_app` 静态组装
- 循环：dsh 可插拔循环；AgentScope `_next_action` 内建循环
- 共同点：都强调"harness 是模型之外的工程"，都可组合、可替换
