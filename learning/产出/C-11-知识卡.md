# C-11 Haystack（deepset）

- **一句话结论**：Haystack 以"**组件化 Pipeline**"为核心——把检索、生成、工具、路由等做成可连接组件（有向图），支持 **HITL 工具拦截**；在"大规模搜索/RAG 型 agent"场景是成熟选择（deepset 企业级）。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | **Pipeline 组件图**（有向无环/带循环扩展）；agent 化通过 agent 组件 |
| I_act | 工具组件；函数调用支持；**HumanInTheLoopTool**（工具执行前拦截人工确认） |
| C 上下文 | 检索管线（document stores、embedders、retrievers）深度集成；RAG 规模化 |
| S 状态 | Document Store 持久化；pipeline 运行状态 |
| V 验证 | 组件级错误处理；HITL 拦截点 |
| 多智能体 | 多 agent 支持（经工具/管道协作）；偏 pipeline 而非自由对话 |

## 核心机制（3 条）

1. **组件即抽象**：`@component` 装饰器把任意逻辑变成 pipeline 节点（输入/输出 schema 声明），连接成图——工程化、可测试、可复用。
2. **搜索/RAG 基因**：从开源搜索框架演进，document store/retriever 生态成熟，适合"企业文档问答/检索增强"型 agent。
3. **HITL 组件化**：`HumanInTheLoopTool` 让"人工确认"成为 pipeline 中的一等组件——与 AgentScope 的 REQUIRE_CONFIRM 同目标、实现为组件。

## 与 AgentScope 对照

- 编排：Haystack pipeline 图（显式组件流）；AgentScope 自由循环 + GoalPipeline
- RAG：Haystack 检索管线成熟；AgentScope RAGMiddleware + KnowledgeBase
- HITL：都是"工具执行前人工确认"，一个组件化、一个权限引擎化
- 定位：Haystack 数据/搜索中心；AgentScope 通用任务中心
