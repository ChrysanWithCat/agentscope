# C-06 CrewAI

- **一句话结论**：CrewAI 以"**角色化团队**"为抽象（Agent=角色，Task=任务，Crew=协作单元），提供两种编排模式——**Crew（顺序/层级协作）与 Flows（事件驱动流）**；是"多智能体原型最快"的代表，2026 年补齐记忆/知识/RAG 可插拔后端。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | 两种：Crew 内 role-based 协作（顺序/层级）；**Flows**（事件驱动、显式流程） |

| C 上下文 | Crew 内任务上下文传递；**记忆后端可插拔**（短期/长期/实体记忆）、知识/RAG 后端（2026 起插件化） |

| 多智能体 | **角色即抽象**：多角色 Crew 天然多智能体；Task 依赖定义顺序 |

## 核心机制（3 条）

1. **角色化抽象**：`Agent(role/goal/backstory)` 让模型以角色身份工作——开发者心智负担低（"告诉它扮演谁"），但控制力弱于图/状态机。
2. **Crew vs Flows 双模式**：Crew=协作拓扑（谁和谁、什么顺序）；Flows=事件驱动流程（触发/状态/条件）——2026 后 Flows 用于生产流程，Crew 用于角色编排。
3. **生产边界**：多智能体协作心智开销低，但确定性控制弱；生产需配合 Flows + 审批 + 外部记忆后端。

## 与 AgentScope 对照

- 抽象：CrewAI 用"角色"（面向用户语义）；AgentScope 用"组件"（面向工程语义）
- 编排：CrewAI 的 Crew/Flows 显式定义；AgentScope 自由循环 + 可选 GoalPipeline/SOP
- 记忆：CrewAI 记忆后端可插拔；AgentScope `AgenticMemoryMiddleware` 三后端——同构
- 适用：CrewAI 适合"快速搭多角色原型"；AgentScope 适合"深度定制生产 harness"
