# A-07 工具系统

- **一句话结论**：`Toolkit` 是工具/MCP/Skill 的**唯一注册中心**，`FunctionTool`（Python 函数）、`MCPTool`（外部 MCP 服务）、`Skill`（技能包）三类工具统一成 `ToolBase` 协议，主循环通过 `Toolkit` 查找并执行。

## 核心类（`tool/`）

| 类 | 作用 |
|---|---|
| `Toolkit` | 注册中心：`add_tool/remove_tool/find_tool`；Agent 构造时挂载 |
| `ToolBase` / `ParamsBase` | 工具抽象（含 `name`、`description`、参数 schema） |
| `FunctionTool` | 把 Python 函数包装成工具（`is_concurrency_safe` 控制并发） |
| `MCPTool` | 适配外部 MCP Server 的工具（经 `MCPClient`） |
| `ToolGroup` | 工具分组（可整体启用/停用） |
| `ToolChoice` | 强制/限制模型调用某工具（`mode: auto/none/指定名`） |
| `RegisteredTool` | 注册表项（工具+来源+校验状态） |
| `ToolMiddlewareBase` | 工具级中间件（执行前后钩子） |

## 内置工具（`tool/_builtin/` 与 `tool/_task/`）

**编码工具**（配合工作空间沙箱）：
- `Bash` / `PowerShell`：shell 执行；`Read`/`Write`/`Edit`/`Glob`/`Grep`：文件操作；`ResetTools`：重置工具状态
- 设计点：这些工具是**无状态工具的标准范例**（`is_concurrency_safe`、执行超时、结果截断）

**任务工具**（任务规划）：`TaskCreate`/`TaskGet`/`TaskList`/`TaskUpdate` —— 配合 InjectionConfig 的任务注入，让 agent 拆解并追踪任务。

**HITL 工具**：`AskUser` —— 触发 `RequireUserConfirmEvent`，暂停等用户输入（`AskUserAnswer`/`AskUserParams`）。

## 工具执行链路（主循环视角）

```
模型输出 ToolCallBlock
  → Toolkit.find_tool(名字)           找不到 → ToolNotFoundError
  → _check_permission（权限引擎）      拒绝/确认 → HITL 暂停
  → 执行工具（顺序或并发批）
  → ToolResultBlock 回写上下文（超长截断 tool_result_limit）
  → 发 ToolCallEnd/ToolResultEnd 事件
```

## 与 harness 通用设计的对应（迁移点）

- **I_act（动作接口）**：FunctionTool=函数调用、MCPTool=MCP 协议、Bash/文件工具=环境交互（对应"CodeAct/代码执行"范式）
- 工具注册表 = 六元组的 I_act 实现；`ToolChoice` = Loop 对动作空间的约束
- 对比 smolagents：AgentScope 的工具是"声明式注册+执行"，smolagents 是"让模型写代码执行"——两种 I_act 风格（见 C-04）
