# C-08 Microsoft Agent Framework

- **一句话结论**：Microsoft Agent Framework 是 **AutoGen + Semantic Kernel 的统一继任者**（.NET/Python 双栈），BUILD 2026 正式发布 **Agent Harness** 概念（Chat client → Chat pipeline → providers → middleware → UX 五层），并原生支持 **A2A 协议** 与 Hosted Agents / CodeAct 预览——微软把"harness"做成了官方架构名词。

## 五层 harness 架构（Microsoft Learn 定义）

```
① Chat client      —— 连接模型（chat completion / streaming）
② Chat pipeline    —— 函数调用、消息注入、按服务调用持久化历史、可选 compaction
③ Agent/Context providers —— 会话级指令、工具、记忆、todo 状态、运行模式、可选能力
④ Middleware/decorators —— 审批处理、可观测性、可选有界循环
⑤ Application UX   —— 流式 UI（终端/Web/Teams）
```

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | pipeline 内的有界循环（bounded looping via middleware）；CodeAct 预览 |
| I_act | function invocation（Chat pipeline 内建）；CodeAct 预览 |
| C 上下文 | pipeline 消息注入 + 可选 compaction；session-scoped providers |
| S 状态 | 服务调用级历史持久化；Hosted Agents（托管） |
| V 验证 | middleware（审批/可观测）；Azure AI Foundry telemetry |
| 多智能体 | **A2A 原生**（A2A cards 内建在 agent 原语）；团队 |

## 核心机制（3 条）

1. **"Harness"成为微软官方名词**：Microsoft Learn 有独立《Agent Harness》概念页，定义"harness 组合现有 building blocks 而非定义独立运行时"——与 DeepSeek/Anthropic 的术语呼应，2026 术语全面收敛。
2. **五层分离**：模型调用（client）与业务逻辑（pipeline/providers）与横切（middleware）与 UI 彻底分层——企业级关注点分离。
3. **A2A 原生 + 托管**：A2A 卡内建 → 跨厂商智能体互通是"默认能力"；Hosted Agents 提供云端托管运行时。

## 与 AgentScope 对照

- 分层：微软五层（client/pipeline/providers/middleware/UX）≈ AgentScope（model 层 / 主循环 / middleware+permission / app 服务层 / 渠道+UI）
- 术语：两边都把 middleware 作横切钩子（微软 approval/observability；AgentScope 7 钩子点）
- A2A：微软原生内建；AgentScope 有 `A2AAgent`（同样支持）
- 编排：微软 pipeline 偏"服务调用"级；AgentScope 自由循环 + 团队工具
