# A-01 总览与架构地图

- **一句话结论**：AgentScope 2.0 是阿里巴巴通义实验室开源的**生产级智能体框架**，核心设计是"**自由推理-行动循环（ReAct）** + 一整套可插拔构建模块 + 一个把智能体变成多租户应用的 FastAPI 服务层"；学习它的关键是**从 `Agent` 入口顺调用链读，不从头扫文件**。

## 核心机制（5 条）

1. **两层架构**：SDK 层（`src/agentscope/agent|message|model|tool|...`）负责"构建单个智能体"；服务层（`src/agentscope/app`）负责"把智能体变成应用"（多租户/多会话/多渠道/持久化/调度）。服务层不重复实现智能体逻辑，只是**按 用户×Agent×会话 实例化并驱动 SDK 的 Agent**。
2. **入口收敛**：系统只有两个入口——SDK 的 `Agent`（`agent/_agent.py`）和服务层的 `create_app`（`app/_app.py`）。所有模块都是它们的"周边件"。
3. **6 个核心子包**（第一梯队）：`agent`（主循环）、`message`（消息模型）、`event`（事件总线）、`model`+`credential`+`formatter`（模型三层）、`tool`（工具系统）、`middleware`+`permission`（横切控制）。
4. **设计哲学**："发挥模型的推理与工具调用能力，而非用严格提示词和固化编排束缚模型" → 所以核心是一个 `_next_action` 决策状态机（Reasoning/Acting/Exit），而不是硬编码流程。
5. **规模与依赖**：478 个 .py / 约 4.3MB；Python ≥3.11；依赖分 extras（models/service/storage/channel/workspace/memory/rag/realtime/tui/a2a），**按需安装**。

## 与入口驱动学习法的衔接

```
create_app（服务入口）──按会话实例化──▶ Agent（SDK 入口）──▶ _reply_impl 主循环
                                        └─▶ 模型 / 工具 / 中间件 / 权限（周边件）
先学 SDK 入口，再学服务入口 → 单向收敛，路径最短
```
