# C-07 AutoGen / AG2

- **一句话结论**：AutoGen（微软研究院开源，社区继任者 AG2）以"**会话式多智能体**"为设计原点——`ConversableAgent` 之间通过**对话**协作，核心模式是 **GroupChat（群聊发言调度）**；适合研究、辩论、多视角探索类场景。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | 会话循环：agent 发言→其他 agent 响应→…；GroupChat 有发言调度器 + 终止条件 |
| I_act | 工具/代码执行（代码 interpreter）；`register_for_llm/execution` 双注册 |
| C 上下文 | 共享对话历史（group chat 内）；human-in-the-loop 发言 |
| S 状态 | 对话状态；研究向（非生产持久化优先） |
| V 验证 | 终止条件配置（max round/发言者规则）；Studio + OTel 可观测 |
| 多智能体 | **对话即编排**：群聊、嵌套对话、人机混合 |

## 核心机制（3 条）

1. **Conversation as orchestration**：智能体不"调用"彼此，而是"对话"——协调是隐式的（由对话内容驱动），适合探索性问题。
2. **GroupChat 调度**：谁发言、按什么顺序、何时终止（speaker selection + termination）——2026 仍是研究热点（自动发言者选择）。
3. **研究→生产的迁移**：AutoGen 长于研究原型（辩论/反思/多视角），生产需配合约束（AG2 在收敛确定性）；微软官方已把接力棒交给 **Microsoft Agent Framework**（见 C-08）。

## 与 AgentScope 对照

- 协调：AutoGen 对话驱动（隐式）；AgentScope 显式组件+工具（委派/汇报）
- 抽象：AutoGen 的 ConversableAgent 面向对话；AgentScope 的 Agent 面向任务循环
- 生态：AutoGen 的研究工具链（autogenstudio）；AgentScope 的生产服务链（create_app）
- 共同点：都支持 human-in-the-loop 与多智能体拓扑；定位都是"灵活多智能体平台"
