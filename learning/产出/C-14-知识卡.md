# C-14 Hermes Agent

- **一句话结论**：Hermes Agent（TypeScript）是 2026 年增长最快的开源 harness 之一（~140K stars），主打"**自我改进的自主智能体**"（self-improving autonomous agents）——把"agent 从经验中学习、改进自身"做成第一特性。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | 自主 agent 循环 + **自我改进回路**（执行后反思、沉淀经验） |
| I_act | 工具系统（TS）；计算机使用/浏览器等环境工具 |
| C 上下文 | 经验/记忆注入（把过去教训带进新任务） |
| S 状态 | 会话/经验持久化（学习成果跨会话保留） |
| V 验证 | 自我评估回路（做了什么、错在哪、下次怎么改） |
| 多智能体 | 多 agent 支持 |

## 核心机制（3 条）

1. **Self-improving 是卖点**：harness 不只"跑循环"，还"从循环中学习"——失败教训/成功经验被结构化保存并注入后续任务（对应 Reflexion 范式的工程化）。
2. **增长现象学**：~140K stars 的增长曲线是 2026 年 harness 热潮的标志（freeCodeCamp 将其与 Claude Code、DeepSeek Harness 并列为 2026 代表）。
3. **自主 vs 受控**：更"自主"（agent 决定自己做什么），护栏相对弱——适合个人自动化工具场景。

## 与 AgentScope 对照

- 学习机制：Hermes 自我改进回路 vs AgentScope 的长期记忆中间件（AgenticMemory/ReMe——AgentScope 也有跨会话经验沉淀，但为"记忆"而非"自我改进"）
- 语言：TS vs Python
- 定位：Hermes 自主个人 agent；AgentScope 生产多租户服务
