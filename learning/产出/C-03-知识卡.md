# C-03 Claude Agent SDK（Anthropic）

- **一句话结论**：Claude Agent SDK 是 Anthropic 的官方 harness——**Claude Code 就运行在它之上**（Anthropic 明确称 SDK 为 "the Agent Harness"）；设计以 **safety-first + MCP 原生 + 工具调用为第一公民**，是 2026 年"应用即 harness"趋势的最佳标本。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | Agent loop（推理-工具调用-观测）；interrupt/恢复；2026 支持"长时运行工作流" |
| I_act | 工具调用为第一公民（结构化 tool use）；**MCP 原生**（stdio/HTTP）；计算机使用（computer use） |
| C 上下文 | 系统提示 + 对话历史；Claude Code 侧做 compaction |
| S 状态 | 会话/项目级状态（Claude Code 的工作区状态） |
| V 验证 | safety 第一：内容策略、权限确认、审计 |
| 多智能体 | subagent 委派（Claude Code 的 recursive composition） |

## 核心机制（3 条）

1. **SDK 即 harness 应用**：Anthropic 明确 Claude Code = SDK 的一个"harness 应用"——学习它 = 解剖最成功的生产 harness 之一（编排循环、工具、记忆、上下文、状态、错误处理、护栏全在一个产品里）。
2. **MCP 是默认工具协议**：Claude 生态把 MCP 做成标准（2024 发明），SDK 原生支持 stdio/HTTP MCP 服务器——"工具从哪来"的答案=任何 MCP 生态。
3. **安全内建**：系统提示注入防护、工具权限确认、细粒度审计；与 OpenAI 的 guardrails 不同，Anthropic 把安全做进循环与权限层。

## 与 AgentScope 对照

- 工具协议：Claude 原生 MCP；AgentScope 经 `MCPTool` 适配同一协议——**MCP 是两者的共同语言**
- 安全：Claude 系统级防护（模型+harness）；AgentScope 权限引擎（harness 级）
- 循环：Claude Agent loop 内建 interrupt/恢复；AgentScope `_next_action` + HITL 停车点——机制同构，命名不同
- 生态：Claude Code 展示了"harness + 编辑器集成 + 终端 UX"的完整形态，AgentScope 的 Console/TUI 是同类尝试
