# D-01 综合自测（理论通关，20 题）

> 覆盖 A（AgentScope）/ B（harness 通用原理）/ C（主流 harness）三模块。先闭卷作答，再对照答案要点；答不出/答错的条目回到对应知识卡。

## 第一部分：AgentScope 核心（A 模块，1-8 题）

**1. AgentScope 的两层架构是什么？两层的入口类分别是什么？**
答案要点：SDK 层（构建智能体，入口 `Agent`）+ 服务层（把智能体变成多租户应用，入口 `create_app`）；服务层驱动 SDK 的 Agent。

**2. `_reply_impl` 主循环的三步结构？`_next_action` 返回哪三种动作？**
答案要点：Step1 检查输入 → Step2 处理事件/新消息 → Step3 推理-行动循环；Reasoning（推理）/ Acting（行动）/ Exit（结束，exit_events=None 表示 HITL 暂停）。

**3. 一次带工具调用的回复，事件序列是什么？**
答案要点：ReplyStart → ModelCallStart → 内容块事件 → ModelCallEnd → ToolCallStart → ToolResult* → ToolCallEnd →（循环）→ ReplyEnd。

**4. Agent 构造的 6 类组件？7 个中间件钩子点？**
答案要点：身份/模型/工具/中间件/状态/卸载器；on_reply/on_reasoning/on_acting/on_check_permission/on_model_call/on_compress_context/on_system_prompt。

**5. 模型/凭据/格式化三层如何解耦？新增厂商要写什么？**
答案要点：Agent 只见 ChatModelBase；厂商差异压到 Credential+Model+Formatter 三件套；新增厂商=写这三件。

**6. 权限引擎的三种决策？HITL 确认流？**
答案要点：ALLOW/REJECT/REQUIRE_CONFIRM；REQUIRE_CONFIRM → RequireUserConfirmEvent（暂停）→ UserConfirmResultEvent（恢复）。

**7. 上下文压缩四件套与 SummarySchema 五段？**
答案要点：压缩/卸载/检索注入/缓存；task_overview/current_state/important_discoveries/next_steps/context_to_preserve。

**8. 服务层三必需件？一次聊天请求的链路？**
答案要点：storage/message_bus/workspace_manager；HTTP → 路由 → ChatService → Agent → 持久化 → AGUI 事件投影。

## 第二部分：Harness 通用原理（B 模块，9-14 题）

**9. 一句话定义 Agent Harness？2026 年哪些大厂在用这个术语？**
答案要点：包在 LLM 外、把它变成可靠 agent 的基础设施（循环/工具/记忆/上下文/状态/错误/护栏）；Anthropic（Claude Code SDK）、OpenAI（Codex）、Microsoft（Agent Framework）、DeepSeek（Agent=Model+Harness）。

**10. 默写六元组 H=⟨?⟩ 并解释每元含义。**
答案要点：H=⟨I_obs, C, L, I_act, S, V⟩：观测输入/上下文组装/控制循环/动作接口/状态持久化/验证恢复。

**11. 五维架构是哪五维？各自的核心决策问题？**
答案要点：Subagent（有无/层级/通信）、Context（存储/压缩/持久化/token 感知）、Tool（注册/扩展/执行/协议）、Safety（审批/隔离/审计）、Orchestration（控制流/规划/事件vs命令式）。

**12. 说出 4 种以上 Agent Loop 范式及停止条件。**
答案要点：ReAct（无工具调用/轮次上限）、Plan-Execute（计划完成/失败）、CodeAct（任务判定/预算）、Reflexion（评估通过/轮次）、PEV（验证通过/失败）。

**13. MCP 与 A2A 的定位差异？**
答案要点：MCP=智能体怎么用工具（工具协议）；A2A=智能体怎么与其他智能体互通（智能体协议）。

**14. 四种多智能体编排拓扑？"何时不该用多智能体"？**
答案要点：handoff 交接/群聊/团队 Leader-Worker/流水线 SOP；任务可被单 agent+工具完成时不该用（避免协调开销）。

## 第三部分：主流 Harness（C 模块，15-20 题）

**15. LangGraph 的核心机制是什么？与自由循环的差异？**
答案要点：显式 StateGraph + 节点级 checkpointer（durable execution + HITL interrupt）；图拓扑在设计期确定 vs AgentScope 运行时决策。

**16. OpenAI Agents SDK 的三个核心概念？guardrail 在循环的什么位置？**
答案要点：Agent/Runner/handoff；guardrail 在循环外（输入前/输出后校验），非工具执行前。

**17. smolagents 的 CodeAct 范式指什么？优缺点？**
答案要点：模型直接写 Python 代码当行动，沙箱执行；自然少转换、可组合 vs 执行安全/结果解析难。

**18. DeepSeek Harness 的"一切皆插件"指什么？Cordis 内核做什么？**
答案要点：模型/工具/技能/会话/沙箱/存储/循环/调度/UI 全部插件化；Cordis 管理 mount/unmount 与依赖。

**19. Microsoft Agent Framework 的五层 harness 架构？**
答案要点：Chat client → Chat pipeline → Agent/Context providers → Middleware/decorators → Application UX。

**20. 用自己的话：harness 决定 agent 性能的说法依据是什么？**
答案要点：同样的模型，换循环停止条件/工具描述质量/上下文策略，性能差异巨大；综述与生产观察（"70% 性能在模型之外"）。
