# C-04 smolagents（HuggingFace）

- **一句话结论**：smolagents 以 **~1000 行源码** 实现极简 harness，核心创新是 **CodeAgent：让模型直接写 Python 代码作为行动**（CodeAct 范式），在沙箱（E2B 等）中执行——原型速度最快（18 行代码、7 分钟跑通基准），但非生产首选。

## 六元组速览

| 维度 | 答案 |
|---|---|
| L 循环 | 极简 agent loop（推理→行动→观测）；无图、无状态机 |
| I_act | **代码执行**：模型输出 Python 代码块 → 沙箱执行 → 打印/返回值回模型；工具=可 import 的 Python 函数（`@tool`） |
| C 上下文 | 对话历史直接拼装（无自动压缩，ephemeral） |
| S 状态 | 无持久化（ephemeral） |
| V 验证 | 手动；沙箱隔离（E2B） |
| 多智能体 | 简单支持（multi-agent） |

## 核心机制（3 条）

1. **CodeAct vs 结构化工具调用**：模型写代码比生成 JSON tool-call 更"自然"（少一层格式转换、可组合逻辑），但代价是**执行安全与结果解析**——必须沙箱。
2. **~1000 行源码 = 最佳教学标本**：读一遍 smolagents 源码 ≈ 理解 harness 的最小骨架（循环+工具+上下文三件事）。
3. **定位**：prototyping winner（最快、最小），not production（无持久化、无治理）——与 LangGraph/AgentScope 的生产定位形成光谱两端。

## 与 AgentScope 对照

- I_act 哲学相反：AgentScope 结构化注册（Toolkit + ToolCallBlock）；smolagents 自由代码（CodeAct）
- AgentScope 内置 Bash 工具=半个 CodeAct（在沙箱里执行 shell），但动作仍由模型经工具调用发起
- 教学价值：smolagents 证明"最小 harness"长什么样；AgentScope 证明"生产 harness"长什么样
